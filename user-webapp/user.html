Interval user page

This is the default user page provided by the Interval framework.

Replace it with your own user.html in your application's data/webapp/ directory. The preparation script keeps your raw user files and generates the compressed files used by the server.

JavaScript callbacks

Put custom browser logic in data/webapp/user.js. The two core callbacks are:

function userInit() {
  // Called when the user page is initialized.
}

function userPong(jsonValue) {
  // Receives JSON data returned by the Interval application.
  console.log("userPong", jsonValue);
}

Other optional hooks can handle configuration and interface controls:

function userConfig(jsonValue) {
  // Handle the user configuration payload.
}

function userInterfaceCfg(key, value) {
  // Return an HTML fragment for a custom interface setting.
  return "";
}

postQuery({command: "userConfig", param: ""}, function () {
  console.log("configuration sent");
});

Icons

Use the existing Interval icon font with an <icon> tag. User-specific glyphs can use the iconUser font loaded from data/webapp/user.ttf:

<icon char="ICON_MIXER" font="iconUser"></icon>

The char value is evaluated as a JavaScript symbol supplied by user.js. Use the existing icon font names and glyph definitions rather than embedding a second icon system.

Internationalization

Resolve user-facing text through the webGUI i18n object instead of hard-coding translated strings:

const label = i18n.gettext("My custom label");
document.querySelector("#status").textContent = label;

For static HTML, use an <i18n> element whose id is the catalogue key:

<i18n id="My custom label"></i18n>

Add the matching key to the supported language JSON catalogues when distributing a custom page.
